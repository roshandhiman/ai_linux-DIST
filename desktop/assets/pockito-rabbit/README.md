# Pockito rabbit

The original white rabbit model and its animation logic are from [Pockito](https://github.com/AkkhileshCod3s/Pockito/tree/a101aacce1e8de49d508cad677813d2677bd77c4), by AkkhileshCod3s and the Wall-Bot contributors. See the upstream [MIT license](LICENSE).

MineOS ships the original GLB and transparent frame sheets rendered from its embedded Idle clip and all 22 states in Pockito’s character state machine. The GTK desktop companion plays those frames without starting a separate browser or GPU renderer. Right-click the rabbit and open **Animations** to preview a state.
